# SSLCertificateTrakcer

<img width="1129" height="684" alt="image" src="https://github.com/user-attachments/assets/ee2a14ee-d474-4b9f-982f-b5463ed323d1" />

This is a SSL Certificate Tracker application made using .Net 10 and Winforms. It allows a user to track different hosts and display meaningful data to the user about the entered hosts SSL Certificate. It shows a status of OK (Days left: Anything 30 days or greater), Expiring Soon (Days Left: 29-0), Expired (Days Left: anything negative) so you can easily keep track of hosts in one place.
